# 大尺寸元素
> 一至三个接近满高的大型主体并排站立，配雪花点缀；隔街远看冲击力强。

【大元素创新（最重要）】
原图的大主体只作为"题材与风格参考"，绝不是造型模板。禁止对原图主体做高保真复绘，禁止只换色、镜像或微调姿势的低差异改版。
每个大主体都必须是重新设计的全新款式：在姿态动作、服饰与纹样、道具、表情神态、配件、轮廓剪影中至少四处显著不同；把生成结果与原图并排对比时，必须一眼看出是同系列的另一款产品，而不是同一张图的重绘。
鼓励在同一主题体系内替换主体类型来拉开差异：例如原图是三个雪人，可以改为圣诞老人+雪人+企鹅的组合；原图是胡桃夹子，可以改为造型、军装、配色完全不同的另一组胡桃夹子或锡兵。前提是主题、风格、目标受众保持一致。

【大元素构图】
整套设计由一至三个大型主体构成，每个主体高度约占画布高度的三分之二到十分之九，呈竖向站立式构图：底部落在画面下缘附近，形成明确的地面感（可用雪堆、草地、底座、花盆等自然收底），不得悬浮在画面中间。
多个主体时并排竖直排列，彼此之间保留清晰的纯白间隔；主体之间在姿态、道具、表情、配色上互有差异，禁止完全相同的复制粘贴，允许构图上的对称呼应。
主体轮廓简洁饱满、体量厚实完整，细节全部做在主体内部（服饰纹样、表情、道具），外轮廓保持连贯易裁切；远看剪影必须一眼可辨认。
除大主体外，只搭配一类小型点缀元素（雪花、星星、小圆点球）散布在主体周围和上方留白处，营造飘落氛围；每个点缀本身轮廓完整、可独立裁切，不做细碎散点群。
尺寸只分两档：接近满高的大主体与小点缀，档差要极其悬殊；禁止出现中间尺寸的元素分散注意力。
